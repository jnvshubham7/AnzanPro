## 📱 Two Applications

### 1️⃣ **AnzanPro Student**

_Interactive abacus learning app for kids aged 4-18_

**Key Features:**

- 🧮 Digital abacus with realistic bead movements
- 🎮 Practice, Quiz & Free learning modes
- 📊 Real-time progress tracking
- 🏆 Achievement badges & rewards
- 🔊 Voice guidance & audio feedback
- 📴 Offline learning support

**Perfect for:** Students, homeschoolers, competition preparation

---

### 2️⃣ **AnzanPro Tutor**

_Professional teaching platform for educators_

**Key Features:**

- 👥 Complete student management system
- 📝 Custom quiz creation tools
- 📊 Advanced analytics & reporting
- 🏫 Class organization & grouping
- 📱 QR code assignment distribution
- 👪 Parent communication portal

**Perfect for:** Teachers, schools, tutoring centers
